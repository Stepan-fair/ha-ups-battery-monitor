# 0.2.0 — reliability and battery passport

Scope approved in the conversation: extend the existing immutable reducer, one
authoritative current stream, standard HA entities/History/Activity, durable
30-second checkpoints and the existing settings/dashboard. No equipment control.

1. Preserve v1 checkpoints and config seeds; add a per-battery passport, full
   calibration history and explicit unconfirmed restart termination. Verify old
   identity, counters, previous-generation recovery and new-battery isolation.
2. Add prediction checkpoints and outcome verification only at an observed
   cutoff, an empirical envelope after three independent clean discharges,
   load-age expiry, time to reserve/cutoff and guided meter verification. Keep
   partial, gapped, saturated and interrupted outcomes out of accuracy claims.
3. Add optional BMS cell/temperature/protection/link diagnostics, HA entities,
   translated settings and dashboard. Battery temperature takes precedence;
   missing optional data never invent zero or stop electrical accounting.
4. Run unit and real-HA tests in isolation, independent whole-change review,
   component-only release build and public GitHub release. Back up only touched
   live files and checkpoint generations, check configuration, then install and
   verify counters, live entities, 60-second history and other dashboard views.
   Any necessary Core restart needs immediate owner approval per Rancho policy.

Physical limits remain explicit: INA226 0.1 ohm is limited to about +/-0.819 A;
software cannot widen that range. No guessed 100%, no automatic deep discharge,
no confirmation of cutoff from HA shutdown alone, no averaging BMS SOC into the
accounting inventory. Real-world accuracy remains unknown until observed.

Review focus: migration and rollback, derived counters after battery replacement,
partial-cycle exclusions, reused load age, empirical errors from distinct
sessions, stale BMS data, source/cutoff changes, checkpoint growth bounds.

Execution log: baseline public repository c20f470; 85 unit tests passed.
